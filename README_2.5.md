# 向克苏鲁许愿 · game2.5 —— 「集曜图鉴」

> 基线：game2.0（3D 祭坛 + 亲手摇签 + 心情驱动解读）
> 本期唯一迭代点：**抽签图鉴 + 抽签次数**（方案 B「积木花园」+ 真实曜日映射 + 择日求签）
> 资产：fang2.5 的 8 个立方体 GLB（七曜：日月火水木金土 + 隐藏宝石）

---

## 〇、这版做了什么

一句话：**求签会掉落「曜日积木」——落在神像四周的地面上，可以拖拽堆叠，点按翻阅其中收纳的签。**

| 需求 | 落地 |
|------|------|
| 方块是积木，自由拖拽堆叠 | 网格自动吸附 + 简化重力 + 拿起/落点/牵引线手感；展台四周环形区可放，神像底座禁放（红色预览 + 弹回） |
| 每日方块 = 真实曜日映射 | `Date.getDay()` → 日/月/火/水/木/金/土曜方；每签 5% 概率额外掉落隐藏「星宝石」 |
| 次数不实体化 | 求签记录（心情/事件/签号/判词全文）存入对应曜日方；点按方块倒叙翻阅该曜日的所有签 |
| 择日求签 | 「所问之日」步进器 + 原生日历跳转（前后各 90 天）；问明天的签 → 解锁明天的曜方 —— 一天可集齐七曜 |
| 方块留在本地 | `localStorage: cth_dex_v1`（cubes / draws / layout 三张表），刷新复原 |
| 64 签收藏图鉴 | 「签谱」8×8 格阵，求得即点亮；点亮格可回看签诗与求得次数 |

未动：求签玩法、签文语料、神像、摇签仪式、心情系统。

## 一、新交互一览

### 1. 曜方积木（3D 场景内）
- **拖拽**：按住方块拖动，金环+牵引线实时预览吸附落点；松手落柱顶，附扩散环与木石叩击声
- **堆叠/重力**：拖到别的方块上自动落顶；抽走中间一块，上方块依序沉降
- **旋转**：拖动中按 `R`（或第二指轻点）转 90°
- **点按**（位移 <7px 且 <400ms）：打开该方块的「曜录」
- **禁放区**：神像底座半径内不可放（红色预览，松手弹回）
- **微动效**：方块呼吸浮动；「今日之曜」脚下有金色呼吸环；每个方块底晕=最近一签的心情色；宝石缓转 + 星尘
- **拂平重排**：集曜浮层底部一键复位布局

### 2. 所问之日
- 首页新增日期行：`‹ 9月19日 · 金曜 · 明天 ›`，点日期文本唤起系统日历
- 非今日求签时，仪式耳语首句变为「向着 X月X日（金曜·明天）伸手……」
- 签卡、抄录、曜录均带「所问之日」

### 3. 三个浮层（纯悬浮语言，Esc/点底/收起关闭）
- **集曜**（入口：首页左下「集曜 x/8」）：八格总览，曜方收录数，宝石未得显示「？？？」；打开时镜头自动俯看积木阵
- **签谱**（入口：「签谱 x/64」）：64 格点亮 + 签诗回看 + 求得次数
- **曜录**（点 3D 方块或集曜格）：单方块的全部签录，**倒叙**，心情色点 + 所问之日 + 求于时刻；点条目回看完整签卡
- 宝石的曜录是「总录」：共祈愿次数 / 集曜进度 / 始于何时 + 全量倒叙

### 4. 镜头
- 结果页「回到神像前」后，若已有曜方，镜头自动俯向积木阵（两段缓动）
- `__ritual.toGarden()`：集曜入口同款俯视

## 二、工程要点

### 资产减负（核心验收：「不增加客户端负担」）
原立方体 GLB 每个 ~100 万顶点 / 55MB（Tripo 高密度雕塑网格 + 4K 贴图），8 个共 **432MB**。
经 gltf-transform 管线：weld → simplify(3%) → 贴图 1024 JPEG → quantize：
**8 个共 9.6MB**（约 5.8 万面/个），肉眼与原模无差（像素级 diff：均值 2.89/255，显著差异 <5% 且集中在轮廓抗锯齿）。
懒加载：只加载已获得的方块，加载中线框坯先行；刷新后按存档错峰恢复（每块间隔 420ms）。

### 两个维度的数据模型
```
cth_dex_v1 {
  cubes:  { golden: {got}, …, gem: {got} }     // 时间维度：曜日 → 方块，最多 8
  draws:  [{ n, grade, mood, q, target, wday, ts, 判词全文×5, san }]  // 次数维度：全量
  layout: { golden: [i, j, k, ry], … }          // 积木摆放
}
```
- 「方块内所有签」= draws 按 wday 过滤、ts 倒叙（draws 上限 2000 条 FIFO）
- 宝石判定独立于曜方：`!cubes.gem && Math.random() < 0.05`

### 手感清单（自动吸附堆叠）
拿起 scale 1.07 + tick；拖动滑移 lerp 0.24 + 90° 旋转缓动；落点环金/红双色；
松手先起后落的抛物线（easeOutCubic×easeOutBack）+ 落地扩散环 + knock；
抽块沉降逐级延迟 45ms 连叩。

### 命中与轨道控制共存
捕获阶段 pointerdown 先 raycast 方块命中代理（不可见包围盒，8 个而已）：
命中 → 方块拖拽（禁用 OrbitControls）；未命中 → 正常转场。点按/拖拽按位移+时长区分。

## 五、已知限制 / 2.6 候选

- 神像 GLB 仍为原 56MB（2.0 遗留；优化管线已备好，可再压到 ~5MB）
- 方块吸附为整格网格（LEGO 手感），未做半格偏移——堆塔对齐优先
- DeviceMotion 摇手机仍未做（沿用 2.0 结论）
- 2.6 候选：签卡图片生成分享；积木阵「晒图」相机位；宝石塔彩蛋（七曜同轴堆塔触发特殊演出）
